## Step 5 — `/deepdive`, issuer profile

Via the real UI path (Directory → search → row), the issuer profile rendered the
credit snapshot. Every KPI carries a **FABRICATED / FAB** badge plus *"Source
unavailable · No persisted document chunk for this metric."* — net leverage 5.7×,

FCF $236m. Gate state surfaced as "0 crit · 4 mat"; authority chips read
`LIVE · UNKNOWN · DERIVED · UNRATIFIED`.

Deep-Dive itself withheld the synthetic figures: *"CP-1 · no analytical output
register"*, *"the reference deal's seeded rail figures are hidden"*, *"Seeded
reference content elsewhere on this page is illustrative."* The 5.68× never
appeared there.

**F-04 surfaced here:** 8 × `404` on `/freshness` endpoints per profile load
(issuer, run, context). Endpoints exist in the OpenAPI spec but are gated behind
`caos_lineage_v2_enabled` (default `False`). Backend 404 is deliberate
(`routes/runs.py:510` — non-enumerable identifiers); the client calls them
regardless, and every freshness indicator collapses to UNKNOWN.
