## Reproduced findings grouped by root cause

### Responsive shell reachability

**F-08 — Cases and Run Console absent from the narrow shell.**

- Reproduce: open `/deep-dive/?case=case_d5e3151a64554296` at 375×812 and
  inventory visible links. Desktop exposed `Case register` and the active `Run`;
  the narrow tool rail hid both and the command palette contained only the six
  top-level workflows.
- Root cause: responsive CSS intentionally hides the workflow tool rail, but
  the command palette indexed workflows and cases—not tool-only destinations.
- Fix: include only tool destinations not already represented by a top-level
  workflow (`Case register` and `Run`) in the existing palette, preserving the
  selected case and run query.
- Regression: both identities navigate from Deep-Dive to Cases and the exact
  selected Run through the palette at 375px.

### Long identifier reflow

**F-09 — Report Studio paper proof overflowed at 375px.**

- Reproduce: open the dense case in `/report-studio/` at 375×812; the document
  width exceeded the viewport.
- Root cause: the 64-character snapshot digest was rendered as plain muted text
  rather than with the existing identifier wrapping utility.
- Fix: apply the existing `mono` class to the snapshot digest; no new CSS.
- Regression: maintained workbench smoke asserts no page-level Report Studio
  overflow at 375px; the final screenshot/capability pass is clean.

### Scanner lifecycle and health

**F-10 — ClamAV served TCP temporarily, then exited after 30 minutes.**

- Reproduce: start `clamav/clamav:1.4` with the repository `clamd.conf`; TCP
  source scanning initially works, but the official entrypoint waits 1,800
  times for `/tmp/clamd.sock` and exits because the mounted config removed it.
- Root cause: the app needs TCP 3310, while the image lifecycle and production
  Compose healthcheck also require the local socket. The config declared only
  TCP.
- Fix: restore `LocalSocket /tmp/clamd.sock` while retaining `TCPSocket 3310`.
- Regression: configuration test asserts both interfaces; the final scanner is
  `running healthy`, returns `PONG`, and accepted synthetic source uploads.

### Local capacity variance

**F-11 — One 24-reader p95 sample exceeded the 1,500ms gate.**

- Reproduce: the first complete rerun measured 1,662.8ms p95 with 0 failures;
  five exact isolated repetitions produced 1,678.9, 1,473.5, 1,154.1,
  1,352.1, and 1,528.7ms.
- Root cause: every endpoint slowed uniformly under local single-process queueing;
  no route dominated and no response failed. This was host/runtime variance, not
  an endpoint-specific regression.
- Disposition: keep the 1,500ms gate unchanged. Three subsequent instrumented
  repetitions passed, followed by two complete clean inventories at 1,105.3ms
  and 1,159.5ms p95. No performance threshold was weakened and no speculative
  application change was made.

Harness-only false positives were corrected without product changes: current-page
self-links are not lost capabilities, and responsive links are compared by
destination rather than presentation label or contextual query string.
