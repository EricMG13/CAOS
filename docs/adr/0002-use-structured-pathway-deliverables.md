# Use structured pathway deliverables

Report Studio produces one structured Deliverable per CAOS pathway rather than a free-form document or the legacy set of overlapping archetypes. Generated analytical blocks remain bound to exact evidence and model identities, analysts edit bounded narrative and composition, shared drafts are revisioned, and only an immutable approved Frozen Deliverable becomes filed PDF/XLSX output. This trades unrestricted layout for reproducibility, consistent committee quality, and exact publication governance.
