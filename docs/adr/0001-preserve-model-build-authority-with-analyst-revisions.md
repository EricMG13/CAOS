# Preserve Model Build authority with analyst revisions

CAOS keeps each application-built Model Build immutable and source-bound. Analyst assumptions are validated through the methodology-owned Assumption Registry and become durable only when an authorized case writer self-releases a recoverable Signed-Off Revision; the latest revision anchored to the current Model Build becomes the Active Analyst Model. This preserves one calculation authority while allowing shared analyst authorship, quarterly rebase, and exact model identity.
